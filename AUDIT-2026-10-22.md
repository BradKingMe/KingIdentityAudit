# KingIdentityAudit code audit — 2026-10-22

Scope: authentication setup, local imports and exports, Microsoft Graph readers, identity linking, comparisons, advisory findings, the AD DS collector, rendering of imported values, and regression coverage. This is a code audit with synthetic data and mocks, not a certification of a live enterprise.

## Confirmed defects repaired

| Area | Defect and correction |
| --- | --- |
| AD collector runtime | PowerShell's case-insensitive `$Domain` parameter collided with `$domain` metadata, coercing the returned object into a string. Metadata now uses a separate variable. The actual script executes in the mock test. |
| Microsoft sign-in | MSAL v5 had no required redirect bridge. A standalone `redirect.html` is now built separately and the exact registration URI is documented. |
| File imports | Async handlers read a detached React event. Both handlers now capture the file input before awaiting, clear it safely, and ignore obsolete imports. |
| Identity linking | A conflicting object ID could fall back to a reused UPN. Returned IDs now take precedence, and cross-tenant device links are refused. |
| Privileged membership | Members from another domain could inherit a local user's status or profile membership through the same account name. Members now retain GUID/SID and use stable identifier matching. Missing identifiers are disclosed. |
| Cloud workspace integrity | Real cloud data could coexist with the synthetic directory or a retained source from another tenant. Live collection removes synthetic context and retains cloud sources only from the same tenant. |
| Pending collection | A finished request could restore data after clear/import/restore. Workspace generation guards discard stale results and abort signals cancel Graph reads. |
| Coverage | Failed and unselected reads were indistinguishable from successful zero-row inventories. Each cloud collection now records complete, partial, failed, or not-selected status. |
| Comparisons | Different tenants, AD domain scopes, profile permission scopes, or incomplete collections could produce misleading changes. These comparisons are now refused with a reason. |
| Import validation | Rendered metadata, capture timestamps, stable identifiers, and collection status were under-validated. Bad metadata, invalid dates, and duplicate identities are rejected. Imported cloud evidence is labeled imported. |
| Graph reader | Added bounded integer limits, a request timeout, repeated-page detection, malformed-record checks, and stricter paging URL checks. Redirects and foreign Graph origins remain rejected before bearer-token transmission. Removed unsupported `$top` from the activated-role query. |
| AD findings | Ordinary computer SPNs no longer enter the user service-account review. Confirmed domain controllers remain in inventory and are excluded from the ordinary unconstrained-delegation finding. |
| Output and scale | Collector creation uses `FileMode.CreateNew` to prevent an output race from overwriting a file. Member lookup is indexed by GUID. Directory tables page 100 accounts; finding dialogs bound rendered evidence to 200 items and disclose the remainder. |

## Verification

- `pnpm test`: 24 passing tests, zero failures and zero skips on the audit machine, including execution of the collector with a temporary mock AD module.
- `pnpm test:browser`: production build plus five passing headless Chrome checks. Tests cover asynchronous imports, malformed metadata, rendering markup as text, pagination/search, the independent authentication bridge, and cancellation using mocked authentication and Graph responses.
- `pnpm audit --prod`: no known production dependency vulnerabilities reported at audit time.
- `git diff --check`: no whitespace errors.

The browser test suite uses a separate temporary profile. No tenant sign-in or live AD query is part of these checks. Test output, exports, recovery files, `.env` files, dependency folders, and build output are ignored by Git.

## Remaining validation and limits

- An authorized test AD domain and Entra/Intune tenant are still needed to validate real module behavior, consent, roles, licensing, paging volume, and authentication browser policies. Mock results do not establish those outcomes.
- The main application bundle remains approximately 585 KB minified (164 KB gzip). Vite emits an advisory chunk-size warning. The application and separate bridge build successfully; further bundle tuning is an optimization opportunity.
- API throttling is reported as failed collection with a coverage warning; automatic retry/backoff is not implemented.
- The project has no reuse license yet. This audit does not choose a license on the maintainer's behalf.
